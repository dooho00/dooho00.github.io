# Font Sources

Unmodified Adobe release fonts, downloaded 2026-09-06:

- Source Serif 4: https://github.com/adobe-fonts/source-serif/tree/release
- Source Sans 3: https://github.com/adobe-fonts/source-sans/tree/release

Regular and Semibold are included as original TTF files for PDF embedding and
original WOFF2 files for self-hosted web use. Each family's copyright notice
and SIL Open Font License 1.1 are included in its adjacent LICENSE.md file.
The deployment build copies the webfonts and these notices into the public
output. Fonts are not modified or sold separately.
