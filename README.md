# Dooho Lee Personal Website

Simple static academic homepage for Dooho Lee.

## Local Preview

Open `index.html` directly in a browser.

## GitHub Pages

This site does not require Node, npm, GitHub Actions, or a build step.

Recommended setting:

```text
Settings -> Pages -> Deploy from a branch -> main -> /root
```

The `docs/` folder contains the same static site if you prefer publishing from `main -> /docs`.
